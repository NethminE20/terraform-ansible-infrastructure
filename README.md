# Terraform + Ansible Local Infrastructure Automation

An Infrastructure as Code project that automates local Docker infrastructure provisioning and configuration using Terraform and Ansible.

## Technologies

- Terraform
- Docker
- Ansible
- GitHub Actions
- Git

## Architecture

The project uses Terraform to provision Docker infrastructure and Ansible to automate configuration and operational tasks.

GitHub Actions provides automated validation and CI checks for Terraform and Ansible configurations.

## Project Features

- Automated Docker infrastructure provisioning
- Reusable Terraform modules
- Multi-environment infrastructure (DEV, QA, PROD)
- Ansible configuration management
- Infrastructure validation
- Automated CI workflows using GitHub Actions
- Security and configuration checks
